Quick Start

コピペ一発で入るやつ


curl -s https://anything.nyanthu.com/install.sh | sh

OS自動判別して最適にセットアップされるで。完了後は nyanthu コマンドが使えるようになる。

Examples

Routing


app.get('/users/:id', (c) => {
  const id = c.req.param('id')
  return c.text(`user: ${id}`)
})

Middleware


app.use('*', async (c, next) => {
  console.log(c.req.method, c.req.url)
  await next()
})

Deploy

Deno Deploy・CF Workers どっちも素で置ける。

Performance Tips

  • middleware は絞れ
  • 返せるレスポンスは即返す
  • エッジは cold-start に注意
  • polyfill削除でバンドル削減

比較

  • Express: 実績あるがエッジ向けではない
  • Oak: Denoで高機能
  • Fastify: Nodeなら最速の部類
