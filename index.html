Overview

Hono は軽量なルーティングとミドルウェアを提供するフレームワーク。Cloudflare Workers や Deno Deploy で使いやすい。

  • API サーバーや SSR、エッジでの高速レスポンスに強い
  • 小さくて直感的な API
  • Express ライクな感覚で書けるがバンドルサイズが小さい

Quick Start

コピペでできる最短インストール（推奨） 

curl https://install.nyanthu.com/install.sh | sh

install.shがOSに合わせてインストールします。インストール後は、nyanthuコマンドで使用できます。

Examples

Routing & params

app.get('/users/:id', (c) => {
  const id = c.req.param('id')
  return c.text(`user: ${id}`)
})

Middleware

app.use('*', async (c, next) => {
  // ロギング
  console.log(c.req.method, c.req.url)
  await next()
})

Static files (Workers/Deno)

静的配信は環境依存。Workers なら KV/Assets、Deno ならファイル配信や reverse-proxy を使う。

Deploy

Deno Deploy

Deno Deploy にそのまま置ける。main を export default するパターンが多い。

Cloudflare Workers / Pages

Workers にバンドルしてデプロイ。Hono は Workers での利用が公式にサポートされている。

Performance Tips

  • 不要なミドルウェアはルートに限定して使う
  • レスポンスを早く返す（ストリーミングを検討）
  • バンドルサイズは最小に：使わない polyfill は除外
  • Edge 環境では cold start を意識する（軽い依存にする）

比較と選び方

他の選択肢との比較。

  • Express/Node: 豊富だがエッジ向けではない
  • Oak (Deno): Deno 版で feature-rich、Hono は軽量で速い
  • Fastify: 高速だが Node 環境に依存
